# This app

This repository is the OpenMS streamlit-template itself: its pages and `src/Workflow.py` are the example app that new apps start from.

In an app made from the template, replace this file with the app's own guidance: what the app does, its own modules and pages, commands that differ from the template's, and its gotchas. `CLAUDE.md` imports it and stays template-owned, so template syncs never conflict on it.
