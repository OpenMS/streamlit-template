Fonts in this folder are served by Streamlit's static file serving (app/static/fonts/...) and named in .streamlit/config.toml.
They are the Latin subsets from the fontsource npm packages, version 5.3.0:

- raleway: SIL Open Font License 1.1, see LICENSE-raleway.txt
- jetbrains-mono: SIL Open Font License 1.1, see LICENSE-jetbrains-mono.txt
- montserrat-alternates: SIL Open Font License 1.1, see LICENSE-montserrat-alternates.txt
